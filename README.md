# 💻 Installation

Clone the repository

```bash
git clone https://github.com/kavyapatel08/My_Portfolio.git
```

Move into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production version

```bash
npm run build
```
